# PDF 3D 뷰어 (안드로이드)

3D PDF(CAD에서 내보낸 PDF) 안의 **U3D 3D 모델**을 휴대폰에서 보는 앱입니다.
윈도우용 PDF 3D 뷰어와 같은 해독 방식을 쓰며, 인터넷 연결 없이 휴대폰 안에서만 동작합니다
(도면 파일이 외부로 전송되지 않습니다).

## 설치 (GitHub 자동 빌드)

1. 이 폴더(`pdf3d-android`)와 `.github/workflows/pdf3d-android.yml`을 GitHub 저장소에 올립니다.
   저장소 맨 위에 `.github` 폴더와 `pdf3d-android` 폴더가 나란히 있어야 합니다.
2. 올리면 **Actions** 탭에서 "PDF 3D Viewer - Android APK" 빌드가 자동으로 돌아갑니다 (약 3~5분).
3. 끝나면 저장소의 **Releases**에 `PDF3DViewer-번호.apk`가 올라옵니다.
   휴대폰 브라우저로 그 페이지를 열어 APK를 눌러 받고 설치하세요.
   ("출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용)
4. 코드를 고쳐서 다시 올리면 새 APK가 만들어지고, 기존 앱 위에 그대로 업데이트 설치됩니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 파일 열기 | 오른쪽 위 폴더 버튼 / 파일 앱·메신저에서 PDF를 "PDF 3D 뷰어로 열기"·"공유" |
| 회전 | 한 손가락 드래그 |
| 확대·축소 | 두 손가락 벌리기/모으기 |
| 이동 | 두 손가락 드래그 |
| 부품 선택 | 부품 탭 → **주황색으로 강조**, 아래에 이름·크기(mm), 부품 목록에서도 같은 색으로 표시 (상위 조립품은 옅은 색) |
| 여러 개 선택 | [여러 개 선택]을 켜고 탭할 때마다 추가/해제 |
| 선택 해제 | 빈 곳 탭, 아래 카드의 X, 또는 뒤로 가기 |
| 부품 목록 | 왼쪽 위 ☰ — 검색, 체크로 보이기/숨기기, 이름 탭으로 선택, 두 번 탭하면 그 부품으로 확대 |
| 보기 방향 | 맞춤 · 등각 · 정면 · 윗면 · 우측, [뷰 더보기]에서 뒷면·아랫면·좌측 |
| 표시 방식 | [음영] 버튼을 누를 때마다 음영 → 윤곽선 → 와이어 → X-ray |
| 단면 | [단면] → X/Y/Z 선택, 슬라이더로 위치, ⇄로 방향 반전 |
| 거리 측정 | [거리 측정] → 두 점을 차례로 탭 (mm, X/Y/Z 성분 표시) |
| 숨기기 | 선택 후 [선택만 보기] / [숨기기], [모두 보이기]로 복구 |
| 기타 (⋮ 메뉴) | 모델 단위(자동/m/mm/inch), 투시·평행 투영, 배경 밝기 |

## 지원 범위

- ✅ U3D 형식 3D PDF (Solid Edge, SolidWorks, Inventor, NX 등), 조립 구조, 부품 색상
- ❌ PRC 형식 3D PDF (감지만 하고 안내), 점진적(progressive) U3D 메시는 기본 해상도로 표시
- ❌ 암호가 걸린 PDF, 텍스처, PDF에 저장된 뷰/주석

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `app/src/main/assets/` | 앱 화면 (`index.html`, `app.js` — 아래 web 폴더에서 만든 결과물) |
| `app/src/main/java/.../MainActivity.java` | 안드로이드 껍데기 (파일 열기, 다른 앱에서 받은 PDF 전달, 뒤로 가기) |
| `app/release.keystore` | 앱 서명 키 (같은 키로 서명해야 업데이트 설치가 됩니다 — 지우지 마세요) |
| `web/src/u3d.js` | U3D 해독기 (윈도우판 `u3d_reader.py`를 자바스크립트로 옮김) |
| `web/src/app.js` | 3D 화면·부품 목록·단면·측정 |
| `web/build-web.sh` | 화면 코드를 고쳤을 때 `assets`를 다시 만드는 스크립트 (Node.js 필요: `npm install` 후 실행) |

U3D 디코딩: ECMA-363 표준과 Intel U3D 참조 구현(Apache-2.0) 참고 · 3D 표시: three.js (MIT) · 압축 해제: pako (MIT)
